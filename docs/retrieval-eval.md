# 中文需求检索评测

`python3 scripts/eval_retrieval.py` 从目标文档提词，按素材目录统计已知项召回。下列需求独立编写，用于验证中文用户从描述想法到收到范例的全链路。追加需求时，先写清相关范例的判断条件，再查看检索结果。

| ID | 中文需求 | 范例相关性标准 |
|---|---|---|
| ZH-01 | 拍一个下班的人在洗衣店里等雨停，十秒内从烦躁变为放松 | 角色在室内等待，以窗外、声响或表演细节体现情绪变化 |
| ZH-02 | 用纸片动画拍两只小动物隔着河用石子传消息 | 有二维材质或平面调度，或用重复动作交代传递关系 |
| ZH-03 | 两个老同学坐在同一张桌前，谁也不先开口，想突出紧张 | 有双人对峙或对坐调度，通过停顿、视线或景别变化传达张力 |
| ZH-04 | 拍清楚师傅手里一块木头怎么慢慢变成勺子 | 有手、工具和材料的近景动作，过程能按可见步骤组织 |
| ZH-05 | 女孩在电梯里发现自己按错楼层，想拍得好笑又自然 | 有封闭空间中的短动作或反应镜，表演节奏能支撑一个简单笑点 |
| ZH-06 | 清晨的面包店开门前，用固定机位拍一个人从黑暗走进暖光 | 固定机位下，人物位置与光区变化共同完成镜头动机 |
| ZH-07 | 在拥挤的早市跟拍卖花的阿姨，画面里要看清她把花递给谁 | 多人共享空间中清楚组织移动主体、交接对象和可跟踪的动作 |
| ZH-08 | 为刚换过书包的小学生写连续三镜，从进门到把旧书包放进柜子 | 有跨镜道具状态或空间锚定可借鉴，能指出动作在两镜之间如何接上 |

每条需求用独立会话执行到检索结束，保存宿主、模型、提交 SHA、Agent 生成的英文查询、前三条返回的范例 ID、排序和 Agent 选用的范例。评审者看到中文需求与范例，隐藏检索分数，按标准判断每条范例是否可借鉴并记下原因。汇总首条相关率和 Top 3 至少一条相关的比例，再分别记录查询漏掉关键特征、没有召回相关范例、选错范例的用例。观察到题材覆盖缺口时，记录缺口和对应需求。

发布前可另用 `tests/behavior-cases.json` 中的零信息路由、仅诊断、素材绑定、平台限制和渲染边界用例跑对话验收。保留实际回复和每条 expected 的判定。
