# 编剧工艺库（Screenwriting Craft）

> 从 19 部编剧经典（菲尔德/斯奈德/麦基《故事》与《对白》/霍克斯特/希克斯/埃格里/克龙/尹迪克/沃尔特/汉森/博克/梅峰/陆军/泊贵洋编/契诃夫/小津等）萃取，来源项目：[jtydhr88/screenwriting-skills](https://github.com/jtydhr88/screenwriting-skills)（个人学习用途；引文权利归原作者与译者）。
> 本文件是**给短剧编剧环节用的方法论层**：语料库（story_level/）告诉你"真实生产者怎么写"，本文件告诉你"好故事为什么成立"。二者叠加使用。

## 1. 立意层：前提与主题（定故事目标时用）

**核心原则**
1. **一句话前提（premise as tyrant，埃格里）**："人物特质 ＋ 导致 ＋ 结局"三段式（如"贪婪导致毁灭"）。一部戏只有一个前提，全剧都在证明它。
2. **主控思想＝价值＋原因（controlling idea，麦基）**："某价值因主人公做了 X 而赢得/失去，因为 Y"。理想/悲观/反讽三型任选其一，先想好高潮再反推。
3. **第三轨（third rail，克龙）**：主人公**渴望的东西** vs 他坚信的**错误信念（misbelief）**。结局＝错误信念被现实击碎的瞬间。超短篇里用 1 个镜头做"信念被打破"的心理反差即可。
4. **戏核（陆军）**：整部戏成立所依赖的那一个核心（动作/道具/境遇）。**检验：抽掉它，戏还成立吗？** 不成立才是戏核。
5. **logline 检验（霍克斯特）**：主人公＋激发事件＋挑战＋赌注＋主题，一句话说给陌生人听、对方眼神不飘。10 秒讲不清的故事，30 镜也讲不清。

**前提五问（希克斯）**：谁是主角？谁是对手？为何对抗？结果改变什么？为何必须**现在**行动？

## 2. 结构层：节拍与转折（拆节拍时用）

**核心原则**
1. **每个节拍必须是一次价值转折（value turn，麦基）**：节拍开场记价值正负（如 安全→危险、希望→绝望），结尾再记。**首尾相同＝纯解说，删掉**，把信息编进有转折的节拍里。
2. **激励事件（inciting incident）要早**：打破平衡的事件在前 1/4 抛出（短剧即第 1-2 镜），并抛出"戏剧大问题"让观众想知道答案。
3. **渐进式复杂化（progressive complications）**：主角每次行动，世界的反击必须**更强**——鸿沟一道比一道宽。反击弱于攻击＝节奏泄气。
4. **三幕的观众心理（希克斯）**：一幕给**吸引力**（愿意跟下去）→ 二幕给**预期**（让观众猜，且猜错）→ 三幕给**满意**（兑现所有预期，但用意料之外的方式）。
5. **起承转合（陆军）**：起＝矛盾尽快亮相、入戏要快；承＝环环紧扣、赌注升级；转＝高潮雷霆万钧（不可避免又出乎意料）；合＝简短有余味。

**Save the Cat 十五拍 → 短剧五拍压缩**（超短篇幅直接用压缩版）：
| 短剧五拍 | 对应 BS2 | 镜头占比 |
|---|---|---|
| ① 钩子+常态（亮类型承诺） | Opening / Set-up | 1-2 镜 |
| ② 触发（激励事件） | Catalyst / Break into 2 | 1 镜 |
| ③ 升级+假象（中点假胜/假败） | Fun & Games / Midpoint | 2-4 镜 |
| ④ 失去一切（最低点） | All is Lost / Dark Night | 1-2 镜 |
| ⑤ 解法+终场（反转收束，与①镜像） | Break into 3 / Finale / Final Image | 2-3 镜 |

**八种开头任选其一**（陆军）：冲突法、布阵法、渲染法、意外法、南辕北辙法、当头一棒法、自报家门法、逼上梁山法。
**八种结尾任选其一**：响雷式、悬而未决式、延伸式、反弹式、点睛式、呼应式、轮回式、结论式。

## 3. 人物与冲突（角色卡、冲突场设计时用）

**核心原则**
1. **三维人物（埃格里）**：生理（体型/缺陷）＋社会（阶级/职业符号）＋心理（欲望+恐惧）。写进角色卡的"心理"栏必须转译为**一个可见的标志性动作**（紧张时摸疤）。
2. **人物塑造 vs 人物真相（麦基）**：外表一套，**压力下的选择**才是真人。主要人物内心不可与外表一致——设计一镜"选择揭底"。
3. **对手要强、给对手一把刀（陆军）**：对手与主角同等强大；用视觉手法加强对手（高位机位、武器、人数），削弱主方。**最强对手常是自己**——用镜像构图/倒影表现。
4. **对立统一（unity of opposites）**：双方被不可妥协的东西**绑定**（同一把钥匙、婚戒、合同）。绑定道具即跨镜一致性道具——正好复用连续性圣经。
5. **冲突三型（埃格里）**：
   - **升级型 rising**（默认用）：每次反击比攻击更强，景别逐镜收紧。
   - **静止型 static**（仅用于蓄力）：用环境细节拖长，1-2 镜内必须转升级。
   - **跳跃型 jumping（严禁）**：跳过情绪步骤＝情节剧。怒→暴怒必须有过渡：嘴角→握拳→青筋→砸物，每级一镜一可见生理反应。
6. **反派动机补全（尹迪克工具箱，按需取用）**：Adler 自卑＋过度补偿（立体反派）；Freud 本我（自由享受邪恶的坏人）；Erikson 阶段跃迁（主角成长弧）；Campbell 英雄之旅（长弧）；Jung 阴影（镜像对手）。

**检查**：主角的欲望比生命重要吗？对手的总和强于主角吗？冲突是升级型吗？有没有"请祥云"（外力解围）？——有则重写，让主角亲手赢。

## 4. 场景与镜头（场拆镜头时用）

**核心原则**
1. **晚进早出（late in / early out）**：开场即在动作中（省铺垫），在冲突解决**之前**切出——未完成感就是下一镜的钩子。天然贴合 10-15s 单镜。
2. **五步场景分析（麦基）**：①谁想要什么、对抗力量直接相对 → ②标开场价值 → ③拆行动/反应节拍 → ④标结尾价值（与开场不同才成立）→ ⑤转折点只能由**动作**或**揭示**制造。
3. **动作优先（action over talk）**：15 秒只够做一件事，把一个可见小动作放大成视觉核心（戒指滑落半截停住、撕合同、锁门）。
4. **转场第三要素**：相邻镜头共享一个物体/光线/动作/声音（前镜的钥匙→后镜的手中钥匙），减少硬切跳戏。
5. **悬念＝预知的美味（阿契尔）**：把钥匙交给观众（炸弹在桌下观众看见了角色没看见），让观众"等着它发生"。
6. **道具要精（陆军六作用）**：结构核心/矛盾助推器/刻画人物/命运象征/主题窗口。一个形象系统贯穿全片、重复出现但不滥用。
7. **细节要妙**：要具体名词——不写"很贵的衣服"，写"双排扣巧克力棕西装"。

**镜头卡增补字段**（加到 story-breakdown 的镜头卡上）：
```
镜头 N | 场 X
画面: 机位/焦距/运动（三件套）
角色: 谁在画面 + 在做什么（动作/微表情）
关键: 本镜不可缺失的信息
value_turn: 开场价值 → 结尾价值（必须不同）
transition_anchor: 与上一镜共享的第三要素
late_in / early_out: 从动作哪一步进、在解决前哪一步切
```

## 5. 视觉潜台词：把对白技巧转译成画面（写每镜 prompt 时用）

Seedance 视频没有真实台词表演空间，麦基《对白》的全部技巧按此转译：

| 对白概念 | 画面转译 |
|---|---|
| **said 说出来的** | 可见口型/动作中的言语行为（喊、耳语、摔话筒） |
| **unsaid 未说的** | 微表情、视线特写、肢体距离（背身、隔门、镜中对视） |
| **unsayable 说不出口的** | 极端压力下的身体选择：颤抖、松手、转身离去 |
| **潜台词（subtext）** | 用构图与机位表达，禁止 on-the-nose 直给（烛光下喊"我爱你"式画面同样禁用） |
| **exposition as ammunition** | 信息携带在动作里、在冲突高点释放：翻出旧照、扔手镯——绝不旁白式交代 |
| **节拍用动名词写** | 镜头动作写"她把戒指褪下半截又停住"（动作/反应+潜文本），不写状态 |
| **角色专属词汇** | 转译为专属服装/手势/习惯动作/标志物（贵族步态、工人的手、烟/刀/信） |
| **两人僵局→三边** | 引入第三人或物件做出口：三人视线三角形、酒杯/信物成焦点 |

## 6. 短篇效率武器（想点子、做系列时用）

1. **"如果＋而且"（荒井晴彦）**：好构想＝两件相去甚远之物的加法（"美女＋罐头""男性＋花样游泳"），用"而且"让偶然被认可。适用于零信息场景的 3 个方向提案。
2. **角色＝演员＋缺点（福田雄一）**：先想"这个形象能带来什么"，再从缺点开始（八成优秀两成缺点）；拼命努力（尤其在撒谎）的角色令人喜爱。
3. **题材即承诺（崔石焕）**：类型是开场第 1 镜就订下的约定——喜剧第 1-2 镜就要有笑点；创新不超过 5-10%；混搭须每个类型都兑现。
4. **两次反转**：一个反转不够，挤两个——放在倒数第三镜和末镜；结尾 bittersweet（悲伤加唯美/团圆加悲伤）余味更长。
5. **写情绪先于写情节（吴胜郁）**：用具体动作路线写情绪（洗手：红水盆、清脆声、雨滴在白衬衫上的黑点），不写"她很悲伤"。
6. **从约束中生长原创（行定勋）**：限制催生创意——"只许用卷心菜和鸡蛋做料理"比"随便创作"更容易出好东西。平台限制（15s、镜头预算）当武器用。
7. **Ozu 语域**：关键信息藏在闲笔与小动作之间；主题用回响物件/空镜呈现，不靠角色嘴说；重大承认只用最小动作（"嗯"）。

## 7. 编剧质检关卡（交付前自检，按阶段过）

| 阶段 | Exit Check |
|---|---|
| 前提 | logline 过陌生人测试？戏核抽掉戏不成立？ |
| 结构 | 每节拍价值有转折？激励事件在前 1/4？高潮"意外又必然"？结尾不止一镜？ |
| 人物 | 主角有缺点+渴望+恐惧？对手更强？人物 ≤5？无请祥云？ |
| 场/镜 | 无纯解说镜？每镜 late in/early out？相邻镜有第三要素？动作优先？ |
| 潜台词 | 无 on-the-nose 画面？信息在动作中释放？节奏奔高潮时镜长在缩短？ |
| 类型 | 类型承诺第 1 镜亮出且全程兑现？两次反转+bittersweet？ |

**诊断顺序**：先结构 → 再人物 → 再潜台词 → 最后画面格式。问题在上游时不要在下游修补。
