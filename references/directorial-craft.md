## 1. 运动配方：起点—变化—终点（Start-Change-End）

**核心原则**
1. **起止边界只读**：起点与终点状态（姿态/重心/目光/双手/持物/空间关系）是序列协议已确认的事实，prompt 只实现"怎么到"，不能改写"到哪"。每镜的 start/end state 字段就是这条边界——与上一镜 end 接不上 = 连续性事故。
2. **有序动作链（ordered motion）**：动作按因果链串行写清——谁行动 → 触发 → 方向/路径 → 接触对象 → 阶段结果（"听见金属响→目光先移向门缝→左手压住本子→身体才离椅背"）。**禁止动作同时发生堆叠**（"转头翻书站起"）；"缓缓/自然/电影感"不能替代路径与结果。
3. **量级是节拍的一部分**：关键动作写幅度——"肩线下沉约五厘米""上身左转约三十度""右手停在离杯沿一掌处"。写不出量级 = 动作没想清。每镜 1-2 处关键量级即可，不必全标。
4. **一镜一个主导变化**：单镜优先服务一个戏剧变化，反应/环境/摄影都为它让路；互不依赖的多线交锋拆镜。
5. **选择性变换四要素**：局部变换（消失/替换/破碎/复原）必须写：①触发 ②目标范围（精确到哪一人/物/表面）③结束几何（留下/暴露什么，不只写"消失"）④**保持项 preserve_set**——同框但不参与变换的人/物/文字表面保持什么位置。不靠堆"其他不变"空泛负面词；模型会吞邻近物时，缩范围或拆阶段。
6. **一条并行通道**：用"与此同时"标出唯一一条并行动作线，且不与主链抢同一只手/同一道视线。

**失败模式**（出现即重写）：起点与关键帧/上一镜不一致 · 大半篇幅写服装场景、动作只剩"自然移动" · 动作全"同时"、先后不明 · 只有情绪标签（震惊—生气—悲伤）无触发与可见过程 · 终点新造了站位/道具转移 · 显式时间段只用掉一半镜长。

## 2. 表演与动作时序（Performance & Action Timing）

**核心原则**
1. **动作预算不是动词计数器**：问"镜长内能否清楚完成必要动作/反应/对白/终态"，而非"最多三个动词"。动作距离、接触复杂度、停顿、表演强度都算预算。
2. **先找动作脊柱（spine）**：从镜头目的反推——哪个动作造成信息/权力/情绪变化？哪个 reaction 让观众读懂变化？有效结构：**一次决断动作 + 一次 reaction**。其余"让画面忙"的装饰最后再加。
3. **接触顺序不可跳步**：先靠近 → 再触碰 → 再施力 → 对象才变化；转手写清哪只手、何时释放/接住；同一只手同一时刻不做不相容任务。
4. **表演不是情绪滑块**：不写"平静30%→紧张70%"。从角色立场选外显通道——目光（寻找/回避/锁定）、呼吸与声音（吸气截断/音量反常降低）、身体（重心撤后/手指停住）、语言（停顿/改称呼/打断）。选**当前景别读得到的最小信号**：远景靠视线转移+手部停顿，近景才用微表情。
5. **注意力交接（attention handoff）**：注意真正转移时才写——"谁/什么拥有注意 → 可见或可听触发 → 注意转给谁"（说话者尾音降低→最近听者先停手→群体让路）。交接两端可以是角色、道具、证据、声源。
6. **起手—发展—落点**：相对时间表达节奏——"起手不动约半秒→话音落下后→动作完成前→结尾停留约一秒"。**结尾必须落住**（reaction landing / 保持终点姿态），余量会被执行端用未授权动作填满。
7. **表演变化承担者（bearer of change）**：只写真正承担本镜变化的角色；状态未变的旁观者不硬加戏。全员不动、变化发生在别人或信息上，同样合法。

## 3. 声音与视听连续性（Sound & A/V Continuity）

**核心原则**
1. **声音分层**：ambience 环境底声 / SFX 事件音效 / dialogue 画内对白 / VO 画外音 / OS 画外说话（保持空间方向）/ music 配乐。各层性质不混。
2. **同轨生成 = 写完整声音时间线**（Seedance generate_audio=True 必须这么做）：按发生顺序列出本镜全部对白/发声/关键 SFX，每条标说话人与逐字内容；所列事件之外只有已声明的底声或静默——**静默也要正面写**（"房间只剩冰箱嗡鸣，两人无话"），并把"不说话"写成可见状态（嘴唇闭合）。排除句只说不要什么，正面句才说清该有什么。
3. **配乐归时间线层，不烧进单镜**：每镜各自生成配乐会在剪辑点产生对不齐的硬切。prompt 显式声明**本镜无配乐层**（实测不写模型会自补配乐），只否定音乐层，勿连带否定同期声与环境底声。配乐的进/出/让位是跨镜时间线决定，逐镜只标相对位置。
4. **环境底声跨镜相接**：相邻镜底声成分与层级一致，换场次才允许变化并写清来源——否则每个切点都"呼"一声换空间。
5. **对白预算**：可发声字 ≈ 4.1×镜长秒数（10s ≈ 40 字）。超预算会被静默截断且不报错。长对白拆镜或延长，不删字不改 VO。
6. **摄影机动机（camera motivation）**：镜头动/不动回答"观众注意为何此刻改变"——reveal 新信息入画 / pressure 距离收紧 / alignment 贴近立场 / relationship 重排权力 / transition 交接。**无动机时 lock-off 是积极选择**：锁定写死构图+画面内什么在动+保持多久；移动写触发+路径+终点景别。locked 与 moving 不同时统治同一区间。

## 4. 场面调度 playbook（Blocking）

**核心原则**
1. **竖屏多人不用上下分层**：先用前景/中景/后景、门框、台阶、桌沿建立纵深 depth；权力表达="谁能接近证据/出口/权力座位"+可信的头肩高低。两人对话也保留**第三人的监听/反应/阻挡位**。
2. **单房对白：运动来自策略**：先标定压力源（出口/座位/桌面证物/声源），谁控制哪个位置；按"说话策略→对方接住或拒绝→物件/目光/空间变化→谁暂时掌权"逐轮推进。反应不总拍脸——不碰纸袋、把钥匙推过边界、让沉默继续都是反应。
3. **证据揭示先问"观众已知什么"**：证据在哪、谁控制、谁先看见、谁看见对方已看见；精确文字须给足可读时间，不靠一闪而过的插入镜。
4. **群体=有方向的关系投影**：只建主轴线（主行动者↔对手）+ 见证者区域 + 入口出口与权力位 + 群体注意方向；用"保护/协作/施压/观察"标阵营并翻译为站位/朝向/视线/距离。一帧内阵营不自相矛盾。
5. **轴线三件套（替代裸写 left/right）**：轴线=甲↔乙两锚点 · working side=摄影机常驻哪侧 · 屏幕方向=甲固定占左/乙固定占右（裸写左右一律指画面左右）。正反打屏幕方向必须互补；过肩镜写明"谁的肩、占画多少"。
6. **越轴要重新记账**：合法手段=同镜穿轴/中性过渡镜/新全景重建；越轴后重声明新 working side，且该镜标注自己是越轴。
7. **动态对象控制权带过切镜**：球/车/武器/信物记录：区域、控制者、方向、目标路线；下一镜从上一镜结束位置与方向继续。
8. **POV 与摄影机所在侧一致**；每次切镜逐项核对位置/面向/持物/谁知道什么。
9. **交付面遮挡（竖屏）**：字幕条/播放控件/进度条会叠在画幅上——已声明遮挡区时，必须被读到的内容（脸/眼神/可读文字/决定性手部动作）不能只落在这些区域；未声明时不猜、不硬避让。优先级：可读文字 > 脸与眼神 > 控件侧。

**画幅适配**：21:9 纵深层次天然适配，轴线策略直接用；9:16 高度变化"更贵"（俯仰迅速吃掉可用高度）——先用水平角度与距离表达权力再动高度，关键内容放中部可读区。

## 5. 镜头语法（Shot Grammar）

**核心原则**
1. **镜头目的先行，景别最后**：顺序=来源关键动作 →观众发生什么变化→从谁的体验组织→起止必须看见什么→才选景别机位。"中景展示人物说话"不算目的。一次打击有两人：说出者 + **承受者（receiver）**——承受者反应必须分配到镜，否则剪辑选不出没拍过的反应。
2. **景别由信息尺度决定，不是情绪旋钮**：远景=地理/力量对比 · 全景=空间/群体权力/同步后果 · 中景=互动/手势/双人策略 · 近景=决定/证据/藏住的反应 · 特写=单一反应成唯一事实 · 大特写=须有"非看不可"理由。情绪升级就换更紧景别是反射性错误。
3. **机位三维度分写**：水平角度（正面/斜侧/正侧/背面——读到多少表情、站谁一侧）· 机位高度（低仰/平视/高俯——谁大于谁，平视=主动的势均力敌）· 焦段意图（广/标准/长——人距显得远近）。三者互不推导；写意图优先于写具体毫米数。
4. **衔接与 30° 规则**：切镜后新镜至少改一项——水平角度 ≥30°/景别/人物关系，否则相邻两镜同景别同角度 = 无效切点。不切镜持续同一景别也是选择（压力累积、被迫直视）。
5. **一场的景别节奏**：先开宽一档建立地理 → 落到工作景别后在其上下一格来回 → 宽景与特写是"离开"标记，用过即回，场尾略放开。
6. **Coverage 思想**：正反打 + 过肩 + 反应镜构成对话覆盖；后果必须可见——说话镜之外要有接收者的反应证明。

**与语料规律合流**：handheld 主导、35/85mm 高频是 CHB/HG 的分布事实；本节给的是"何时该反惯例"的判断依据（如无动机时 lock-off、特写须有理由）。

## 6. 镜头设计与场景地理（Shot Craft & Geography）

**核心原则**
1. **原文落实优先**：剧本每段（动作/对白/声音/画面文字）都有处理——由镜头落实/有理由省略/有意重复。几段可合于一镜，重要揭示可一拆多镜。
2. **动作落实表：每个权威动作只有一个主落实镜**：转手/开门/揭面/取证记：主落实镜 + 动作前后事实。只有主落实镜能把状态从"前"改"后"；前一镜不得无源提前变后，后一镜不得再完整表演一次（这正是序列协议 start/end state 的工艺依据）。
3. **可见性判断**：构图决定观众此刻知道什么。每个关键事实单独写：展示还是暂扣、可见/可听载体、揭示条件。逆光剪影/前景遮挡可保护揭示，但用光保护不改光源身份方向。本镜负责展示证据/关键反应时，不能为画面好看遮住载体。
4. **场景地理建模**：入口出口/固定锚点/前中后景/谁能看见接近什么/人物面向与视线/轴线 working side/双手持物归属。调度即策略：靠近=施压或结盟，转身=拒绝，占出口=控制，碰证据=暴露知情。
5. **起止边界与冻结关键帧**：设定图/起始帧只决定本镜开始状态，不能预置动作结果；超过 5-8s 的镜按精确状态边界拆，或显式接受宽规格。

## 7. 导演质检关卡（交付前自检）

| 层 | Exit Check |
|---|---|
| 运动 | 起手接上一镜终点？动作串行带方向幅度？有量级锚点？结尾落住？preserve_set 写了？ |
| 表演 | 一次决断动作+一次反应？接触顺序不跳步？景别与表演信号匹配？无情绪滑块？ |
| 声音 | 声音时间线完整（静默正面写）？声明无配乐层？底声跨镜一致？对白在预算内？ |
| 调度 | 站位有策略来源？轴线三件套可比较？正反打互补？越轴有记账？第三人位保留？ |
| 镜头 | 目的先行？承受者反应有镜承担？≥30°或景别变化？工作景别节奏成立？ |
| 连续 | 动作落实唯一主镜？start/end 与相邻镜逐字段一致？无提前变后/重复表演？ |

**诊断顺序**：先连续性（§6/§1）→ 再调度与镜头（§4/§5）→ 再表演时序（§2）→ 最后声音（§3）。
