# Gemini Omni 中文口播错读与音色修复闭环（TTS 对位 + 三层语音门禁）

> 来源：多镜头混音与真人出镜中文口播短片实测沉淀。
> **定位说明**：本 Skill 默认职责是产出分镜提示词与方言规范；当宿主环境同时配备视频渲染与音频接口工具链且用户要求端到端出片、配音或语音返修交付时，强制执行本闭环。

## 0. 触发条件（何时切入本流程）

`360p` 最小样片或 `1080p` 初片出现以下任一信号时，**停止重试 Omni 生片赌概率**，保留 Omni 实拍嘴部动作帧，直接切入本闭环：
1. **中英混读或近音错字**：如将英文产品型号（示例 `X8`）连续读作 `N8`、多音/近音词读偏（`评估→彭古`、`补贴→补整`、`教你→叫你`）；
2. **跨镜声场与音色漂移**：室内/户外/车内景别切换后说话人声线明显变人；
3. **吞字/语速压缩含混**：评审或试听指出特定秒数咬字不清（如高频短起音词因后续高倍率加速压缩而丢失介音）。

---

## 1. 上游提示词与参考图前置设定（生片前防错）

1. **台词节奏预算**：Omni 中文真人口播每镜控制在 **24–35 汉字 / 8–10s**（约 **3.3–3.8 字/秒**），避开长难从句堆砌。
2. **音频解耦原则**：凡计划后期统一重配人声的项目，Omni 分镜提示词中**删除所有配乐/BGM 描述**（仅写轻环境底声或静默），避免原片 BGM 污染伴奏或带偏唇动节奏。
3. **零字幕/零徽标正向锁**：
   - 严禁出现引号台词（改用冒号引出）与 `dealership glass facade` 等易诱发品牌徽标回召的场景词（易导致墙面或玻璃出现自绘圆标或字母斜标）；
   - 场景写为无品牌暗示建筑：`minimalist architectural gallery, completely blank matte bare walls with zero wall badges, zero circular emblems`。遵循独立行极简负面约束写法（见 `references/model-adaptation.md` §7.2）：
     ```text
     No subtitles.
     No on-screen text.
     No watermarks or brand badges.
     ```
4. **含水印参考图预处理（参考图重绘规范）**：
   - 来源参考图带媒体角标或文字条时，**先本地裁剪**去掉边角水印/文字条（保留主体完整轮廓），传入裁剪后的 `.jpg`（`image/jpeg`），且在图像重绘接口指定输出 `response_format.mime_type="image/jpeg"`（部分模型传 `image/png` 会报 400）；
   - 重绘提示词**严禁出现** `"remove watermarks"` / `"erase text"` 字样（易触发 `image_safety` 安全拦截报错），改用正向背景补全重绘：`"Recreate the clean studio or minimalist architectural background seamlessly around the subject keeping exact geometry and proportions, bare matte finish, blank solid label/plate surface, clean corners."`
5. **`360p` 2 镜先行定音路线**：先产 2 镜 `360p`（如室内开篇 + 户外交替）并**听测+转写原声**；只要发现中英混读错字或跨镜音色漂移，立即敲定全量 `1080p` 后走下文第 2–5 步对位替换，不再重复抽卡。

---

## 2. 阶段一：原片唇动时间窗提取与原声彻底静音

1. **20ms RMS 包络提取（`-34` 到 `-36 dB`）**：对每镜已出 `1080p` 视频原音按 `15–20ms` 步长计算 RMS 能量，以 `-34` ~ `-36 dB` 为阈值，合并间距 `≤ 0.14s` 的音节碎片，落盘 `speech_spans.json`，结构为 `{shot_id: [[v0, v1, dur], ...]}`（例：`"shot3": [[0.70, 1.46, 0.76], [1.94, 3.78, 1.84]]`），并与剧本意群逐句对应。
2. **严禁低音量留底原声**：最终合成时必须对原视频轨完全静音（`-an` 或 `-map 0:v:0` 丢弃原音频）。**不可保留微弱原声当「现场感底噪」**，否则背景里仍会隐约漏出被替换前的错读鬼音。

---

## 3. 阶段二：Voice Design 统一音色与汉语提示铁律（`gemini-3.8-flash-tts`）

1. **锁死单一说话人 ID**：通过 Voice Design（调用参数遵循官方 TTS API 文档 / SDK）创建唯一说话人标识 `<VOICE_ID>`，全片所有镜头复用同一个接口配置：
   ```python
   client.interactions.create(
       model="gemini-3.8-flash-tts",
       input=[{"type": "user_input", "content": [{"type": "text", "text": text,
           "annotations": [{"type": "speech_metadata", "style": style}]}]}],
       response_format={"type": "audio"},
       generation_config={"speech_config": [{"voice": VOICE_ID}]},
   )
   ```
   按**完整单句**一次合成保证语调连贯，再按分句切分对齐。
2. **绝对禁止在句首放置 `<short pause>`**：实测文本索引 `0` 位放置 `<short pause>` 会诱发模型在正式开口前吐出「嗯」「啊」「把」等前置气声杂音。`<short pause>` **只能用在句中意群之间**。
   - *抢救例外*：若某条重录的音色与正文咬字极稳，仅在正片前多出一个独立 `<0.20s` 杂音且中间存在明显静默隔离（如 `[0.27, 0.435]` 后 `[1.005]` 才起读），在分句映射 `CLAUSE_MAP` 中直接跳过前段杂音区间切片即可，不必重录赌运气。
3. **禁止正文写拼音，慎用 `speech_metadata.style` 拉丁拼音纠音**：
   - 正文写入拼音会被 TTS 原样照读成英文字母；
   - 对高频塌缩词强行在 `speech_metadata.style` 塞入带声调拉丁拼音（如 `dì-yī`），反而易打乱普通话韵律甚至诱发额外口语填充词（如句尾凭空加字`"…啊"`）。
4. **同元音并音词（如「第一」塌缩成「底/地」）的正交解法**：
   - 当 `[i]+[i]` 或同类邻近元音在逗号/停顿前反复并音成单音节时，改用**中文空格拆开词法绑定**——在 `text` 中写作 **`"第 一，"`**，并在 `speech_metadata.style` 明确约束 `read exact text verbatim with zero added filler particles`，实测可一次性分离出清晰完整的双音节且无冗余语气词。

## 4. 阶段三：限幅语速对齐（`atempo ∈ [0.90, 1.06]`）与混音规范

1. **`CLAUSE_MAP` 结构与限幅规则**：对齐表定义为 `{shot_id: (target_vid_dur, [(tts_t0, tts_t1, vid_t0, vid_t1), ...])}`。其中 `target_vid_dur` 为该镜对齐后音频的总输出秒数（对齐原视频时长），`(tts_t0, tts_t1)` 为该分句在干声 `raw_{shot}.wav` 中的起止秒数（切片可附加微量防截断保护垫得实际物理片段时长 `actual_t` ≈ `tts_t1 - tts_t0`），`(vid_t0, vid_t1)` 锚定自 `speech_spans.json`。计算 `raw_ratio = actual_t / (vid_t1 - vid_t0)`，将 `ffmpeg atempo` 严格锁定在 **`[0.90, 1.06]`**：
   - **禁止使用 `1.18x` 等高倍率加速**（高倍率压缩会挤扁短起音合音节的介音与声母清晰度，导致听感歧义）；
   - **略超窗口时优先微扩尾端**：当 `raw_ratio > 1.06` 时，允许将 `vid_t1` 适度延展进后继静默呼吸窗，使 `tempo` 落在 `0.95–1.05`；
   - **无呼吸窗可借或仍突破 `[0.90, 1.06]` 的兜底边界**：不得侵占下一子句张嘴起点（须至少保留 `0.08s` 静音隔离），此时应微调句中停顿重录更紧凑的干声或精简冗余虚词，严禁硬压 `>1.06x` 或提前截断尾音。
2. **独立配乐与侧链闪避**：用纯器乐音乐模型（如 `lyria-3.5`，调用规范见官方音频 API 文档）生成无伴唱配乐（`-18 dB` 起调），通过 `ffmpeg sidechaincompress` 在人声窗口自动闪避，片头淡入 `0.6s`、片尾淡出 `2.2s`。
3. **封装与响度基线**：`concat` 拼接及终混显式固定 `fps=24,setpts=N/(24*TB)` + `-r 24 -fps_mode cfr` 与 `apad,atrim=0:<total_dur>`，消除可变帧率与尾帧静音差；目标响度 `I: -19..-17 LUFS`、`max_volume ≤ -1.5 dB`（零削波）。

## 5. 阶段四：三层语音门禁与独立新上下文盲审（缺一不可）

每次生成干声 WAV 与终混成片后（须提取最终 MP4 含 BGM 音轨），均须完成以下三层核验：

| 层级 | 执行工具 / 手段（接口遵循对应 API 文档） | 抓什么问题 | 单用盲区（为何不能只跑这一层） |
|---|---|---|---|
| **L1 逐字转写对比** | `gemini-3.5-transcribe`（`verbatim` + `timestamp_granularities=["word"]`） | 抓明显错字、漏字与英文数字错读（如 `光→刚`、`第一→底`、`X8→X3/X24`） | ① 会静默吞掉口语多余填充词（如 `"那个啊"`）；② 配乐混音下容易因同音候选把正确发音转成「之初/何时/装修」 |
| **L2 语音清晰度审计** | 多模态音频理解模型（如 `gemini-4-hydrogen`）全轨听审 | 输出 `MM:SS.d` 时间戳文本，专检疑点秒数、辅音起始瞬态是否被 BGM 拍点掩蔽 | 依赖模型判断，不能替代人耳或宿主直接试听把关 |
| **L3 亲自试听切片** | 用音频播放或宿主媒体试听工具直接听干声 WAV 与**含配乐终混切片 WAV**（必听疑点区间与起止句） | 终局裁定是「真实读音含混/加字杂音」还是「L1 同音选词误差」 | — |

**返修与独立新上下文盲审闭环**：
1. 若发现局部不达标：**仅对失败镜**备份原录音（如 `backup_v1/`）→ 微调断词/停顿重录 → 复跑该镜 `L1 + L3` → 只重跑 `atempo` 对齐与混音 → 对**终版 MP4 提取的含配乐音轨重跑完整 `L1 + L2 + L3`**。
2. **独立新上下文盲审（防自判假绿）**：另起一个无任何修改过程记忆的独立审片代理，**只传递 `[终版 MP4 路径, 人物与产品参考原图, C1–C5 客观验收清单]`**（绝不交代曾改过哪里）。清单标准如下：
   - **C1 技术流与响度**：`ffprobe` / `blackdetect` / `freezedetect` / `ebur128` 确认分辨率帧率 CFR 无黑帧静帧、`max_volume ≤ -1.5 dB` 与响度达标；
   - **C2 主体与场景一致**：抽帧比对人物/目标产品外观跨镜无漂移；
   - **C3 语音与剧本吻合**：提取终片音轨运行 `L1` 转写并切段直接试听确认咬字无含混、BGM 无掩蔽；
   - **C4 口型同步与切点**：`scdet` 切点切换干净，抽样口型条与音声起止对齐；
   - **C5 零文字与防品牌回召**：全画幅抽帧叠加 **`4×` 局部放大裁剪检视**（重点裁剪主体产品正背面商标/文字区、背景玻璃反光墙面、道具表面纹饰及画面四角），确认零字幕/零品牌徽标/零水印。
   全部 C1–C5 `PASS` 方可交付。
