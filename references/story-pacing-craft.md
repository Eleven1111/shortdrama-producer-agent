# 剧作与节奏工艺库（Story Craft & Pacing）

> 来源：Higgsfield《The Trigger》5,429 jobs 的**剧本层与节奏层**提炼（6 场短片：接单 → 等待 → 认出 → 决断 → 前史 → 收束）。
> 与 `screenwriting-craft.md`（前提/价值转折/冲突）、`sequence-protocol.md`（节拍分桶）、`directorial-craft.md` §2/§13（时序/落点）、`story_level/*`（真实节拍密度数据）互补：本文件专管**信息配额、台词替代、切率曲线、场次语法**。

## 0. 何时读

- 短剧开场没钩子 / 观众 3 秒划走 → §1 VO logline 开场
- 台词写不出来、或想把交代压短 → §2 信息配额 + §3 单据作为对白 + §4 情报蒙太奇
- 高潮不够硬（尤其"人没动手"的戏）→ §5 负向节拍
- 场与场"节奏一个味"、情绪没有起伏 → §6 场次语法 + §7 切率配方
- 闪回/梦境/时态切换会乱 → §8 时态视觉锚

## 1. 提问式 VO logline 开场（首尾闭环）

实测开场旁白：
```
"Could you ever imagine... that ordering a cup of coffee...
 and a slice of apple pie... would get you, in return...
 an order to kill a man? ...Neither could I."
```
- **用疑问句把 logline 变成观众代入装置**；末句由角色自答（`Neither could I.`）确立第一人称
- VO 立独立法则块并声明全片不变：`旁白声音(最高优先级,贯穿全片不变)` + 完整音色规格 + 反向约束
- 音色规格写法（可直接套）：年龄/音区/共鸣位置/质地（沙哑粗粝、低频毛刺）/咬字（含混往回吞、词尾吞掉、辅音软化）/音量（压着嗓子、密度高像贴耳）/节奏（紧凑往前推、句尾干脆收掉）/情绪（平直不加重任何词）+ `绝不清亮、绝不年轻、绝不播音腔、绝不是老人颤抖声`
- 适用：短剧第一集前 10 秒；也可把同一段 VO 的末句挪到最后一集做闭环

## 2. 信息配额纪律（开场不给脸）

实测写进"格式模式"的硬规则：
```
七个镜头,共20秒。第一至第六镜头绝不出现他的正面或侧脸;
第七镜头是本片第一次给到他的脸。
```
- 悬念不靠情节，靠**配额**：整场只给背影/手/桌面/纸面，最后一镜才交人脸
- 同源技巧：`最后一拍才停止眨眼`——把最贵的资产留到最后交付
- 用法：主角首次登场、反派现形、关键道具亮相，都可设"前 N 镜不给 / 第 N+1 镜第一次给"的配额规则，并写进格式块

## 3. 单据作为对白（diegetic text as dialogue）

全片现场台词仅 **1 句**（`"Your check."`），信息全部走纸面：
```
1 COFFEE 2.50 / 1 APPLE PIE 4.75 / TOTAL 7.25
——（虚线撕口之下）——
YOUR NEW ORDER / 447 MAPLE ST, QUEENS NY / APT 2, SECOND FLOOR
MALE, BLACK, EARLY 40S, ATHLETIC BUILD / PRIORITY: HIGH
```
- 摄影机配套：微距 + 极缓下移 + 焦点逐行咬字，每行停留到可读（见 `continuity-laws.md` §6 文字白名单）
- **纸面版面即揭示结构**：上半是午餐价目（日常），虚线之下才是杀单（转折）——道具的版式直接承担节奏与反转
- 可迁移：把交代段落改写为短信/工单/病历/榜单特写，省台词省时长，且天然规避"AI 腔台词"

## 4. 情报蒙太奇装置（用卡片压缩交代）

实测目标作息卡片（同一装置全片复用）：
```
WASHES HIS CAR SATURDAYS / 89TH ST POOL / SWIMS AT NIGHT / ALONE, 21:00
RUNS THE PARK EVERY MORNING, 8 AM / TAKES THE 7 LINE / LIMPS, BROWN CASE
PARKING LEVEL 3 / SILVER SEDAN / MIDNIGHT / THE HOTEL
WINDOW: 00:00 - 04:00 / DRIVES ALONE, NO ESCORT
```
- 清单化的生活规律 → 建立"这是一份职业"的压迫感，同时 3 秒交代完目标背景
- 可迁移：反派/猎物的日常规律卡片堆叠；每张一个地点一个时间，配一条硬切

## 5. 负向节拍承担高潮

- 高潮 = **没发生的动作**：`TERRENCE DOES NOT SHOOT`（独立节拍块，实测 ×116）——扣扳机的手停住
- 前提是**债务已在前史场建立**（当年在阿富汗把他从屋顶拖下来的士兵）
- 结构模板：仪式（接单）→ 等待（抵达）→ 认出（眼睛）→ 决断（不动作）→ 前史（补因）→ 收束（VO 闭环）
- 与 `screenwriting-craft.md` 的价值转折配合：让"不开枪"翻转主角的价值（职业 → 人）

## 6. 按戏剧功能命名的场次语法

实测块：
```
GRAMMAR — CHAMBER grammar (waiting, watching, deciding)
Frame absolutely level, Dutch zero, long lens, camera locked with a few
centimetres of barely perceptible drift. The face stays 80cm+ from the lens;
only hands, metal and fabric enter the near zone.
```
- 把同类场打包成**可复用的具名语法**（构图/焦段/漂移量/主体距离/近景准入），一场一语法，全片复用
- 建议自建语法库：chamber（等待/凝视/决断）、chase（追）、confrontation（对峙）、tender（亲密）、ritual（仪式）——每种 4–5 条硬参数
- 与 `directorial-craft.md` §4/§5 的分工：那边是通用调度与镜头语法，这边是**按功能封装的场次配方**

## 7. 切率配方（切率随戏剧功能变化）

实测数据（本项目最硬的节奏规律）：

| 功能 | 硬切 | 叠化 | 中位时长 | 配方 |
|---|---|---|---|---|
| 等待 / 凝视 | 195 | 11 | 20s | **长镜静观**，极少切换，一次呼吸一拍 |
| 决断 / 反应 | **402** | 0 | 12s | **短镜密集硬切**，切率拉满 |
| 收束 / 片尾 | 314 | **186** | 30s | **叠化放缓**，时间流逝感 |
| 前史 / 闪回 | 241 | 74 | 20s | 硬切推进 + 叠化过渡 |

口诀：**蓄势慢、决断快、收束飘**。写分镜表时给每场标一个"切率档位"，避免全片一个节奏。

## 8. 时态视觉锚（闪回用独立固定风格块）

- 前史场专属块：`FILM STYLE — Afghanistan war flashback, fixed for the whole film`（暖金色记忆调、16mm 质感、低饱和、军事真实硬约束）
- 现代场另一套（冷青 / 《杀手》橄榄绿）；回忆场用"梦境般浓重柔焦"
- 观众**靠色彩与质感识别时态**，无需字幕提示；同一时态的所有镜头共用同一个 style 块（逐字复制）
- 与 `style-bible.md` 的分工：style bible 管项目级风格，时态锚是**同一项目内的多套并行风格块**

## 9. 多镜头单 prompt = 一个节奏单元 + 变体试拍

- 实测 SCENE 01：60% 为多镜头 prompt，均 3.8 镜/条、最多 16 镜/条、中位 6s/镜；一场一次生成，硬切标记内嵌
- 优势：省去多段拼接的身份漂移风险；节奏在生成内完成（`prompt-templates.md` 的多镜格式可直接承载）
- **变体试拍**：同一场保留多版本（实测开场 7 镜有 20s 与 22.5s 两版）——把"同场多版本"当分镜预演与时长微调，择优或拼合
- 秒级 beat sheet 前置：前史场实测 6,149 个时间码——**先写秒表，再写画面**

## 10. 红线速查

- [ ] 第一集前 10 秒有 logline 钩子（疑问句 + 角色自答），VO 有音色规格块
- [ ] 主角/反派/关键道具设了"信息配额"规则并写进格式块
- [ ] 台词能转成单据/清单/卡片的，不写台词
- [ ] 高潮若为"不动作"，前史已建立债务
- [ ] 每场标了场次语法（具名）+ 切率档位（蓄势/决断/收束）
- [ ] 多时态项目：每个时态一套固定 style 块，逐字复制
- [ ] 节奏在 prompt 里用秒表写好，不留给后期
