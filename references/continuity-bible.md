# 连续性圣经（Continuity Bible）

短剧模式下，**角色/场景/道具的外观定义升级为"剧集级"**：全剧所有镜头复用同一份定义，杜绝跨镜头漂移。
只用于短剧模式；单镜头模式仍用镜头内的 `<<<name>>>` 锚定即可。

## 核心原则

1. **定义一次，全剧复用**：圣经里的外观定义是唯一权威；每镜 prompt 直接引用，不重新发明。
2. **锚定名全局唯一**：`<<<name>>>` 的名字在全剧中保持不变（含大小写）。
3. **变化必须显式**：角色中途换装/受伤/道具状态变化，在圣经"状态轴"里登记，镜头引用当前状态。
4. **负面约束锁定**：跨镜头一致性用 `Characters, props, environment identical across every cut` + `no identity drift`。

## 三本圣经

### 角色圣经（每角色一段）

```yaml
<<<name>>>:
  类型: character          # character | prop | environment
  锚定名: <全剧统一名，小写>
  外观基线:                 # 首次定义即完整，之后不再重复
    体型: ...
    发型/发色: ...
    肤色: ...
    服装: 逐件（材质+颜色+细节）
    饰品/特征: ...          # 痣/伤疤/纹身/道具绑定
  CHARACTER REF: appearance only
  状态轴:                  # 随时间/剧情变化的状态，默认"基线"
    baseline: 基线外观
    state_1: 变化描述（如: 受伤满脸血 / 换装 / 情绪化）
  参考图: [imageN]          # 有则绑定
```

### 场景圣经（每场景一段）

```yaml
<<<scene_name>>>:
  类型: environment
  地点与结构: <建筑/空间结构一句话>
  材质细节: <墙面/地面/门窗材质>
  固定陈设: <不可移动的道具，跨镜头一致>
  光线基线: <主光方向/光质/色调，复用规律库 H5>
  状态轴:   <如: 白天→黄昏→夜 / 完好→破损>
```

### 道具圣经（有状态变化的道具才登记）

```yaml
<<<prop_name>>>:
  类型: prop
  外观: <一句话>
  状态轴: <如: 完整→碎裂 / 熄灭→燃烧>
  绑定角色: <常随哪个角色出现>
```

## 使用规则

- **写镜头 prompt 前**：从圣经拷贝该镜涉及的角色/场景/道具定义到 prompt（`<<<name>>> — <外观>...`），只拷贝，不改写。
- **圣经只在变化时更新**：换装/受伤/场景破损 → 更新对应状态轴；其余情况圣经保持只读。
- **一致性负面约束**：每镜 prompt 都带 `no identity drift, characters identical across every cut`。
- **同名冲突**：两个相似角色用不同锚定名（`young_lulu` / `lulu`），禁止重名。

## 交付格式（短剧模式的连续性区块）

短剧模式产出在 shotlist 前先给"连续性圣经"区块（角色/场景/道具三节），用户确认后，shotlist 里的每条 prompt 都引用它。用户后续说"继续/下一批"时，圣经是唯一复用来源。
