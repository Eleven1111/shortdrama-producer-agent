# 故事拆解协议（Story Breakdown）

把"一个想法"拆成"一部短剧"：故事目标 → 节拍 → 场 → 镜头 → 镜头预算。
只用于**短剧模式**；单镜头模式跳过本文件。

> **编剧方法论层**：本文件是流程骨架；故事质量的方法论（前提/主控思想、价值转折、人物冲突、视觉潜台词、质检关卡）见 `screenwriting-craft.md`。拆解时两文件叠加使用。
> **系列短剧（≥3 集）**：拆解前先建项目美学圣经（渲染域/命门句/色彩配方/签名，见 `style-bible.md`），圣经摘要块逐字复用为每镜风格锚前缀。

## 拆解层级

```
想法（一句 vibe / 概念）
  └─ 故事目标 + 最终结局（结局先行，倒推）
       └─ 节拍 beats（3-8 个：开端/冲突/转折/高潮/收束）
            └─ 场 scenes（按时间/地点分组，每场 1-3 个节拍）
                 └─ 镜头 shots（每场 2-6 个，每镜 = 1 条 prompt）
                      └─ 镜头预算（总镜头数 → 生成批次）
```

## 五步拆解法

### 1. 定故事目标与最终结局（先定终点）
- 一句话：主角想要什么 + 最后得到什么 / 失去什么 / 变成什么。
- 例："雨夜女孩想找到母亲，结局在巷口昏黄路灯下与母亲重逢，但母亲已不认得她。"

### 2. 拆节拍（beats，3-8 个）
每个节拍 = 一个叙事功能。按三幕结构兜底：
- 第一幕（1-2 拍）：引入主角、常态世界、闯入事件
- 第二幕（2-3 拍）：冲突升级、受阻、转折
- 第三幕（1-2 拍）：高潮、结局
每个节拍写：**一句话动作 + 情绪走向**（如"发现母亲照片 → 从平静到激动"）。
- **价值转折强制项**（`screenwriting-craft.md` §2）：每个节拍首尾各记一次价值正负（安全→危险、希望→绝望…）。**首尾相同＝纯解说拍，删掉**，信息编进有转折的拍里。
- **激励事件前置**：打破平衡的事件放在第 1-2 拍，抛出"观众想知道答案"的戏剧大问题。
- **升级阶梯**：主角每次行动，反击必须更强（渐进式复杂化）；高潮"不可避免又出乎意料"。
- 超短篇幅用压缩节拍骨架：钩子+常态 → 触发 → 升级+中点假象 → 失去一切 → 解法+终场反转（详见 `screenwriting-craft.md` §2 五拍表）。

### 3. 节拍分组为场（scenes）
- 规则：**同时间 + 同地点 = 一场**；场景切换即换场。
- 每场写：地点 + 时间 + 光线基调（复用规律库 H5）+ 本场叙事任务。

### 4. 场拆镜头（shots）
每镜用一张"镜头卡"描述，字段（对齐规律库硬规则）：
```
镜头 N | 场 X
画面: 机位/焦距/运动（三件套）
角色: 谁在画面 + 在做什么（动作/微表情）
关键: 本镜不可缺失的信息（转场点/特写对象/道具状态）
value_turn: 开场价值 → 结尾价值（必须不同，纯解说镜删/改写）
transition_anchor: 与上一镜共享的第三要素（物体/光线/动作/声音）
late_in / early_out: 从动作哪一步进、在冲突解决前哪一步切
```
- **晚进早出**：开场即在动作中，冲突解决前切出——未完成感是下一镜的钩子（`screenwriting-craft.md` §4）。
- **动作优先**：15 秒只够做一件事，把一个可见小动作放大成视觉核心；信息在动作中释放（弹药式交代，禁旁白式解说）。
- 对白/潜台词的画面转译规则见 `screenwriting-craft.md` §5（unsaid→微表情/视线/道具，unsayable→压力下的身体选择）。
- **调度与镜头判断**：站位策略、轴线三件套（甲↔乙锚点 · working side · 屏幕方向）、景别由信息尺度决定、机位三维度分写，见 `directorial-craft.md` §4/§5；每镜运动链与声音时间线的写法见其 §1/§2/§3。

### 5. 定镜头预算与批次
- 短剧时长估算：1 镜 ≈ 15s（Seedance 2.0 上限），10 镜 ≈ 2.5 分钟。
- 批次规则：单次产出建议 **≤6 镜**（一次生成太多会稀释质量）；总镜头 >6 时拆多批，批次间按序列协议续写。
- 预算确认：拆解后把镜头数与用户对齐（"共 12 镜，分 2 批，每批 6 镜"），用户同意再进连续层。

## 短剧大纲模板（交付物格式）

```yaml
短剧: <标题>
故事目标: <主角想做什么>
最终结局: <结局一句话>
镜头预算: <总数>（分 <批数> 批，每批 <N> 镜）

节拍:
  - beat 1: <一句话动作>（情绪: <走向>）
  - beat 2: ...

场:
  - 场 1: <地点/时间/光线> — <叙事任务>
    镜头: 2-6 个
  - 场 2: ...

shotlist:  # 完整分镜表见交付格式
```

## 编剧质检关卡（拆解完成后、进连续层之前）

按 `screenwriting-craft.md` §7 过一遍，全过才进分镜：

- [ ] logline 过陌生人测试；戏核抽掉戏不成立
- [ ] 每节拍价值有转折，无纯解说拍；激励事件在前 1/4
- [ ] 主角有缺点+渴望+恐惧；对手更强；无外力解围（请祥云）
- [ ] 高潮"不可避免又出乎意料"；结尾有余味（两次反转+bittersweet 可选加分）
- [ ] 冲突是升级型；情绪有过渡阶梯，无跳跃
- [ ] 类型承诺第 1 镜亮出，全程兑现

问题在上游（前提/结构）时不要在下游（镜头卡）修补——退回对应步骤重拆。

## 边界

- 用户只要"一个镜头"→ 走单镜头模式，不拆故事。
- 用户给的已是完整剧本/分镜 → 跳过 1-4 步，直接从第 5 步核对预算，沿用其剧本。
- 叙事类短剧必须走完整五步；纯氛围/纯产品展示类可降级为"场景清单"（列场，不拆节拍）。
