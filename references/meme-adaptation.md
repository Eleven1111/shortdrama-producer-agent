# 梗图 / 段子改编（adapt 模式）

其他入口的输入是「一个还没成形的想法」，这个模式的输入是**一个已经成立的笑话**：一张网络热梗图，或一段文字段子。
任务因此反过来了：不是把想法发展成故事，而是**把笑点原样保住，翻译成能拍的分镜**。改编最常见的死法是笑点在翻译途中丢了，
片子拍得很漂亮，但不好笑。

> **证据等级：[未验证]。** 本文件不是语料蒸馏（Seedance 语料与 The Trigger 都不含喜剧），是按喜剧结构常识写的设计规则，
> 2026-10-20 只做过一轮最小样本（3 张合成梗图 + 3 个段子），2026-10-21 按那轮 runner 报出的缺口修订一次。规则若与实测冲突，以实测为准并回写本文件。

## 0. 何时进入

| 输入 | 路由 |
|---|---|
| 一张图 + 「改成短剧 / 拍成视频 / 做成短剧」，图里有配字、多格、表情包脸 | **adapt** |
| 一段笑话 / 段子 / 冷笑话 / 对话体 / 一问一答 + 「拍成短剧」 | **adapt** |
| 社交帖截图（推文 / 微博 / 小红书，帖子文字 + 嵌入图或视频帧） | **adapt**。原文层只取帖子正文和图内文字；平台界面、账号名、点赞数、「翻译自 X 语」不算原文层，不进梗卡也不进成片 |
| 配字长图（图片只当背景，笑点全在叠加的多行文字里） | **adapt**，按段子处理：图片只给情境线索，不当画面参考 |
| 一张普通照片（无笑点），「用这张图里的人做个视频」 | 不是 adapt，走 `asset-binding.md` |
| 「做个搞笑视频」（没给具体笑话） | 不是 adapt，走 `clarification-protocol.md` 零信息兜底 |

判断标准只有一个：**输入里已经有包袱了吗？** 有就进 adapt。

进入后与默认流程的差异：

- **跳过 Step 1 的维度计数**：笑话自带主体、情境和情绪，按维度数会误判成「零信息」去问问题。
- **跳过 Step 3.5 素材绑定**：梗图默认是**故事来源**，不是要继承的素材，不进绑定表（理由见 §4）。
- **会议层默认关**（同单镜头）。用户说「开会」才开。评审会里捣蛋鬼那一席的职能，由 §8 的盲复述测试承担。
- 其余步骤照常：Step 1.5 平台检查、Step 2 检索、Step 4 十条硬规则、Step 5/5.5 质检、Step 6 交付；差异在 §6。

## 1. 拆梗：先产出梗卡

读图用 Read 直接看。多格图按阅读顺序编号，**图中文字逐字抄下来**，不要改写。

```
梗卡
来源类型: 梗图（单格 / 多格 / 对比 / 配字表情包）| 段子（叙事 / 对话 / 一问一答 / 三连）
原文层:   图中逐字文字，或段子原文
情境:     谁、在哪、发生了什么（一句）
笑点机制: 主机制 + 可选辅机制（从 §2 表里选）
包袱一句话: 观众在哪一刻、因为什么笑
笑点载体: 画面 / 台词 / 字幕 / 声音（可多选，标出主载体）
预期线:   铺垫让观众预期的是 ___，包袱给的是 ___
出处/IP:  原创 | 网络梗（出处 …）| 含真人 / 影视剧照 / 动漫角色 / 商标 → §4
能拍性:   A 视觉可拍 | B 台词可拍 | C 文字依赖 → §3
```

**看不懂的梗不要装懂。** 改编把梗理解错是目标层的失败，后面的分镜全部作废。

- 出处或含义不确定时，能联网就查（梗名 + 含义 + 出处）；不能联网就在梗卡里标 `出处: UNVERIFIED`。
- 理解把握不大时，用选项式确认，这是「猜错代价高」那一类（`clarification-protocol.md`）：
  「这张图我理解成 A ___ / B ___，按 A 做，不对你说一声」。说完接着生成，不停下来等。
- **原文本身有错**（机翻、错别字、指代不清）：梗卡「原文层」照抄原样，另起一行 `理解: ___` 写出你修正后的意思，并在交付说明里点出这处修正。包袱句按修正后的意思写；用户明确要保留原句（错本身是笑点）时才照抄。

## 2. 笑点机制 → 分镜骨架

| 机制 | 怎么认 | 分镜骨架 | 关键镜 |
|---|---|---|---|
| 预期违背 / 反转 | 前面铺 X，结尾给非 X | 铺垫 → 包袱 | 包袱镜，峰值落在最后一帧 |
| 反差对比（期望 vs 现实、别人家 vs 我家） | 两格并列 | 两镜**同机位、同景别、同构图**，只换内容 | 第二镜。match cut 本身就是笑点，构图一变就没了 |
| 误会 / 信息差 | 观众知道、角色不知道，或反过来 | 先给观众信息，再看角色犯错 | 角色犯错那一刻的反应 |
| 三连 / 重复升级 | 同一结构出现三次，第三次打破 | 三拍同节奏、同句式，第三拍破 | 第三拍。前两拍要几乎一样，差别越小越好笑 |
| 夸张 / 荒诞升级 | 一件小事被推到离谱 | 正常 → 一点点不对 → 离谱 | 离谱那一镜，所有人仍然当真 |
| 反应型（表情包本体是一张脸） | 图里只有一个表情 | 先给刺激，再给反应 | 反应镜，hold 1–2 秒 |
| 语境错位（古装腔进职场、新闻播报腔讲家务） | 一种语境的腔调、规矩或仪式，被原封不动搬进另一个不相干的语境 | 先用一镜把现实语境立住（越日常越好），包袱镜里角色用另一语境的全套腔调认真执行，周围一切照旧 | 腔调落地的那一句。外来语境只靠台词和表演带进来，不换布景和服装，否则就成了穿越，错位感没了 |
| 谐音 / 字形 / 数字 / 术语梗 | 笑点在语言本身 | 见 §3 C 级 | — |

**分镜必须脱离原图也能成立。** 每一镜都要写清本镜的画面、机位和人物关系。禁止写「构图照原图」「同原图」「参考梗图」：
观众没见过原图，视频模型也看不到原图，靠原图补全的镜头在成片里是空的。

## 3. 能拍性分级

- **A 视觉可拍**：笑点在画面关系里。直接按 §2 骨架拍。
- **B 台词可拍**：笑点在一句话里。
  - 包袱台词用 `DIALOGUE LOCK` 锁原文（`continuity-laws.md` §1）：**保留原句，不意译、不润色**。
  - 包袱台词前留 0.5–1 秒停顿。这一拍空白是笑点的一部分，不是可以剪掉的冗余。
  - 一镜只安排一个人说包袱台词，降低口型错配的风险。台词按 `continuity-laws.md` §8 的中文范式写进引号。
  - **方言台词**（东北话、粤语、川渝话等）：方言是笑点的一部分时才保留，否则用普通话。保留时分三层写：
    ① 字面：`DIALOGUE LOCK` 锁方言原字（「咋滴啊」不改成「怎么了」）；
    ② 口音：在 `AUDIO` 段写一句口音规格，如 `Northeastern Mandarin accent, flat deadpan delivery, slight rising tone on the last word`，只写口音和语调，不写「搞笑地说」；
    ③ 降级：交付说明里注明「口音不稳时，用普通话念同一句原文，包袱靠字面仍成立」。方言字不认识的（粤语生僻字），台词后加括号注普通话意思，供配音参考，不进字幕。
    模型对方言口音的控制力未经实测 [未验证]；粤语等与普通话差异大的方言，优先建议后期配音。
- **C 文字依赖**：谐音、字形、数字、行业术语。画面没法直接承载，按顺序试三条路：
  1. **情境化**：找一个让双关的两层意思同时在画面上成立的情境。字面义交给画面，引申义交给情境。
  2. **字幕或道具承载**，**后期字幕优先**：把包袱写进交付里的后期字幕清单，逐字可控，不受模型生成文字的错字和乱码影响。
     只有当这行字必须是故事里的物件（角色要看见它、对它起反应，比如一块招牌、一张成绩单）时，才改用道具上的字
     （`TEXT LOCK` 白名单，文字可读时摄影机锁定，见 `continuity-laws.md` §6），并在说明里提示：道具文字可能生成错，需要抽帧核对。
  3. **如实说拍不了**：给一个**同机制**的替代包袱，交付时标明「已替换，非原梗」。

  禁止把谐音梗意译成另一句不好笑的话，然后声称保留了原梗。

## 4. 版权与肖像：只借机制，不借形象

梗图里经常有明星、网红、路人、影视剧照、动漫角色。默认处理：

- **原创角色重演**：换人、换装、换场景，只保留**情境关系 + 包袱**。好笑的是机制，不是那张脸。
- prompt 和参考图里**不出现真人姓名、剧名、角色名**，不把原梗图当人物参考绑定，不描写可识别的真人外貌。
- 流行语本身（文字层）可以用。
- **商标词只是顺带出现、不是笑点**（如「支付宝付款码」里的「支付宝」）：直接换成通用说法（付款码），不用另作提示。判据：换掉后包袱还成立，就换。
- **原图是未成年真人**：必须原创重演，不描写可识别的五官或标志特征；儿童角色不安排被嘲笑、受伤或身体羞辱的包袱。
- **原图涉及真实新闻事件**（骚乱、灾难、具体地名的冲突）：地点泛化，不在字幕或旁白里断言未核实的事件细节；暴力背景只拍事后痕迹，并读 `action-scene-craft.md` 的留白原则。
- **包袱本身就是商标词**（花呗、某个 App 名、某款产品名）：台词里原样保留这个词，换成通用说法包袱就没了。
  画面里不出现 logo、App 界面、手机屏幕、产品外观，NEGATIVE 写 `no logo, no brand name visible, no app interface`。
  交付说明里提示：部分平台的广告审核可能把台词或字幕里的商标词当作软广，发布前请自行确认。用户要商用投放时，
  另给一版同机制的通用词替代，标明「已替换，非原梗」。
- 用户明确要「还原原图人物」时：不写真人肖像描述，说明肖像权和平台下架的风险，建议用户自己准备有授权的素材，再走 `asset-binding.md`。

## 5. 喜剧骨架（替代短剧五拍）

`story-breakdown.md` 和 `screenwriting-craft.md` §2 的五拍表是为戏剧准备的，套在笑话上会把笑话拆坏。adapt 模式改用：

| 拍 | 功能 | 镜数 | 时长 |
|---|---|---|---|
| ① 钩子 | 前 3 秒抛出情境或冲突（竖屏的划走线） | 1 | ≤3s |
| ② 铺垫 | 建立预期 | 1–2 | — |
| ③ 误导（可选） | 加固错误预期 | 0–1 | — |
| ④ 包袱 | 打破预期，峰值落在本镜最后一帧（`directorial-craft.md` §13 Reveal/punch） | 1 | — |
| ⑤ 补刀 / 反应（可选） | 反应镜 hold 1–2s，或第二个包袱 | 0–1 | — |

节奏规则：

- **镜数跟着笑话走**。一问一答的段子 2–3 镜，三连 4–5 镜，别为了像短剧硬凑到 6 镜。
- **单条 15s prompt 内硬切建议 ≤5 镜**（平均每镜 ≥3s）。超了先合并：一问一答收进同一个双人镜，不要一句话切一个反打。
  三连的「前两拍几乎一样」靠同机位、同句式保证，不靠每句话单独一镜。
- **台词密度上限：中文约每秒 4–5 字**（15s 内全部台词约 60–75 字），包袱前的停顿另算，不能被挤掉。
  超了先删铺垫里的台词，不删、不改包袱句。
- 以上两条上限是设计值 [未验证]，依据是镜头过碎时口型和反打容易糊；出片实测与之冲突时，以实测为准并回写。
- 包袱前留一拍空白（停顿或静默）。包袱之后**不加解释镜**。
- **铺垫不得说破包袱的因果**。铺垫镜的字幕、旁白、服装、道具只给情境，不提前交代「为什么好笑」。配字长图里交代原因的那几行，要么改成画面让观众自己看出来，要么挪到包袱镜一起出。自检：遮住包袱镜，只看前面几镜，读者不该能猜出包袱。
- **配字长图的原句不能逐行搬成字幕**。原配字通常是「前因 + 结论」的叙述，整段上字幕就是剧透。逐句分流：能拍成画面的变成画面；拍不出来又必需的前提，压成一句不含结论的情境字幕（如「早高峰，公交站」）；交代结论或原因的句子删掉，交给包袱镜。
- **包袱镜不配复述画面的字幕**。包袱是台词时，字幕只放这句台词的原文；包袱是画面时，包袱镜不加字幕。自检：把每条字幕单独读一遍，如果它说出了观众应该自己看出来的东西，就删。
- **删结论，不删前提**。上面两条只删「说出结论或原因」的句子；观众看懂包袱必需的前提（在哪、刚发生了什么）要留下：画面交代不清时，用一句不含结论的情境字幕补上（如「骚乱后的街」）。A 级视觉梗尤其不能把字幕删光，只剩表情给观众读。
- **钩子镜不摆出答案**。第 1 镜交代情境，不直接摆出包袱要揭晓的对比（如「只有它完好」）：要揭晓的那一半留到包袱镜再亮。
- **第一人称配字**（「我扮演银行卡，大家可以把钱存我这」这类自述）：逐句判断。交代设定的句子（我是谁、我扮成什么、我在干嘛）交给画面，不说出口；只有包袱句做角色台词。设定句说出口，包袱就从反转降成递进。画面实在交代不清设定时，宁可让别的角色问一句（「你扮的是……？」），也不让主角自己先说。
- 总长 ≤15s：一条 prompt 内用硬切时间码分镜（`story-pacing-craft.md` 的多镜头单 prompt 节奏单元）。
  这种单条交付**不跑** `scripts/continuity_check.py`：它检查的是多条 prompt 之间的编号和首尾衔接，单条 prompt 找不到序列头，
  必然报 ERROR。这是不适用，不是断链。交付时写一句「continuity_check 不适用（单条 prompt）」即可；`diagnose_prompt.py` 照跑。
  总长 >15s：每镜一条 prompt，交付前跑 `scripts/continuity_check.py`。
- adapt 模式**不执行**以下戏剧条款：每拍价值转折强制项、「失去一切」、两次反转 + bittersweet、主角缺点 + 渴望 + 恐惧。
  `screenwriting-craft.md` §7 的关卡只保留「类型承诺第 1 镜亮出」；logline 陌生人测试由 §8 盲复述测试替代。

## 6. 默认值（只在 adapt 模式下覆盖）

- **画幅 9:16**，时长按 §5 骨架算（多数 10–30s），平台限制照 Step 1.5。
- **Step 2 检索**：语料里没有喜剧，关键词用**情境**（`office desk boss walks in`），不用 `comedy / funny`。只借 OPTICS 密度，不借调性。
- **声音**：环境声 + 台词 + 画面事件引起的音效。禁止罐头笑声和提示笑点的音效或音乐（`anti-slop-lexicon.md` 喜剧行）。
- **文字**：Step 5.5 的 `No on-screen text` 基线**保留**，不让模型自己生成字。包袱靠文字时，写进交付里的「后期字幕清单」（时间码 + 逐字）。道具文字例外，走 `TEXT LOCK`；两者同在一条 prompt 时，基线固定写成 `No on-screen text except the TEXT LOCK whitelist`，不要同时写裸的 `No on-screen text`。
- **prompt 语言**（全局文档的说法不一致，adapt 模式按这里写）：中文正文 + 英文全大写段头（`STYLE` / `LIGHTING` / `AUDIO` / `NEGATIVE` 等，独立成行）
  + 英文否定基线（`no on-screen text, no subtitles, no watermark` / `Diegetic sound only, no music` 等）。台词保留原文。
  中文否定可写「无 / 没有 / 不出现 / 不加 / 禁止 / 不要 X」。`diagnose_prompt.py` 把否定剥到该分句末（逗号、句号为界，顿号不算界）；
  一个否定只管自己所在的分句，跨逗号的要求会被当成正面要求（测试见 `tests/test_diagnose_negation.py`）。
- **约束短语对照表**（正文写中文时，下列约束仍用英文原样写；`diagnose_prompt.py` 只认这些写法，近义改写会被报缺失）：

  | 约束 | 写这句（任选其一） | 别写成 |
  |---|---|---|
  | 同期声、无配乐 | `Diegetic sound only, no music` | `no BGM`、`natural sound` |
  | 无屏幕文字 | `No on-screen text, no subtitles, no watermark` | `no captions`、`clean frame` |
  | 快门节奏 | `natural 180-degree shutter cadence` | `natural motion blur` |
  | 硬切时间码 | `HARD CUT at 5.0s`，或时间段 `0.0s–5.0s` | `cut to`、`then` |
  | 方位以镜头为准 | `All left/right = FROM CAMERA` | `left side of the screen` |
  | 非 3D 渲染 | `NOT 3D render, NOT cartoon` | `realistic` |
  | 锁定焦段 | `Lens locked, one lens per shot`，或 `no zoom` | `fixed focal length` |
  | 无鱼眼 | `rectilinear, no fisheye` | `no lens distortion` |
  | 首帧非空 | `First frame is occupied`，或 `no empty first frame` | `first frame never empty` |
  | 不看镜头 | `No one looks into the lens` | `avoid eye contact with camera` |
  | 不漂浮 | `Nothing floats, no floaty motion` | `grounded physics` |
  | 手部正确 | `Hands fully formed, correct number of fingers` | `perfect hands` |

  段头也必须是独立成行的英文全大写：`SCENE CONTEXT` `LIGHTING` `CAMERA` `OPTICS` `PHYSICS` `STYLE` `ACTION TIMING` `AUDIO`。
- **焦段**：写视角度数（`47°` / `29°`），不写 mm 数值。度数写法只适用于 Seedance 原生方言（`anti-slop-lexicon.md` §5），
  目标是其他模型时改写成空间感受描述。
- **表演**：角色不知道自己好笑，认真地演（deadpan），不挤眉弄眼，不对镜头笑（伪纪录片除外）。
- **风格锚**（Step 4 第 9 条），按机制选：
  - 生活流写实：竖屏短剧质感，手机高度的固定机位，自然光
  - 情景喜剧：固定机位、平光、全景交代空间关系
  - 伪纪录片：手持、角色偶尔直视镜头
  - 夸张荒诞：Edgar Wright 式快切推镜，或周星驰式一本正经的夸张

## 7. 交付

adapt 模式的交付格式**以本节为准**，覆盖 SKILL.md Step 6 的「只交 prompt + ≤3 条说明」：笑话改编要靠梗卡和分镜表才能核对包袱有没有丢，
只交 prompt 等于把验收的依据扔了。`full-direction` 下按这个顺序给：

1. **梗卡**（§1）
2. **分镜表**：`| 镜 | 拍 | 时长 | 机位/焦段/运动 | 画面 | 台词/声音 | 后期字幕 |`
3. **prompt**（Step 4 规则不变；>1 条 prompt 且同一角色跨镜时，按 Step 4.6 先出设定图 prompt）
4. **后期字幕清单**（有才给）
5. **≤3 条说明**：替换了什么、IP 怎么处理、C 级梗走了哪条路

用户说「只要提示词」时，仍然先在内部做完梗卡和分镜，只交 prompt。

## 8. 验收：盲复述测试

把**分镜表**（不带梗卡、不带原文）交给一个没见过原梗的读者，问：「这段视频哪里好笑？用一句话说出包袱。」

- **通过**：复述出来的包袱与梗卡里的「包袱一句话」是同一个意思。
- **不通过**：退回 §2/§3 改结构，不要在 prompt 措辞上修补。
- **负控**：删掉包袱镜（和补刀镜）再测一次。读者的回答按三档判：
  1. **说不出包袱**（「没讲完」「不知道笑点在哪」）：负控有效。
  2. **说出的是原包袱**：负控失败。要么笑点其实不在包袱镜（结构有问题），要么这次测试太宽松。
  3. **说出的是铺垫里的次级笑点**（例如铺垫本身就有一个小反差，读者把它当成了笑点）：负控仍算有效，因为主包袱确实随包袱镜一起消失了。
     但如果读者高把握地认定这个次级笑点就是全片的笑点，说明铺垫抢了包袱的戏，回 §5 把铺垫压平。

**判定只看两个二值指标**：① 复述是否与梗卡的「包袱一句话」同义；② 负控是否没被猜中原包袱。两项都过就算通过。
读者自报的把握度（高 / 中 / 低）和「被说破了吗」的评语只作改进线索，**不作为通过或回退的门槛**。依据：2026-10-21 三张真实梗图回归 6 轮，同一写法的把握度在「高」和「中」之间来回跳，单个读者给出的一档差距是打分噪声。读者在多轮中反复指出的同一个问题才值得改。

读者最好是新开的会话或子代理。如果只能在同一个上下文里自测，交付时标明「盲复述为自测，非独立」。
