# 项目美学圣经（Style Bible）

> 方法论萃取自 [fanchengchen1-collab/super-director](https://github.com/fanchengchen1-collab/super-director)（CC BY-NC-ND 4.0，本文仅做概念级转述与 Seedance 适配；原方法权利归原作者）——数百集 AI 短剧产线打磨的"项目级视觉方向层"。
> 解决的问题：**多集/系列短剧"60 集像同一部剧"**。角色/场景/道具级一致性由 `continuity-bible.md` 管；全剧统一的色调/光影/质感/签名元素由本文件管。两者叠加。

## 0. 何时用

- **系列/多集短剧**（≥3 集）→ 必须先建圣经再拆集，"没有圣经不开机"。
- 单支短剧 → 可用 10 分钟粗版（只做第 0 步 + 命门句 + 色彩配方）。
- 圣经一旦建立，**所有镜头 prompt 的风格锚与 SCENE CONTEXT 从圣经取材**，禁止逐镜即兴发挥方向层。

## 1. 第 0 步：双开关声明（先于一切）

开工前锁死两个正交开关，写进圣经首部，全剧逐字复用：

```
渲染域 render domain = A 写实真人 | B 2D动漫 | C 3DCG   ← 域不定，七步全歪；中途换域=重开圣经
媒介模式 media mode = 短剧(9:16竖屏) | 横屏 | 电影
```

**域声明块（每条 prompt 的固定前缀，逐字复用）**：
- A 域：`photorealistic, live-action, cinematic, real light physics`
- B 域：`2D anime, cel animation, hand-drawn`
- C 域：`3D CG, cinematic render` / `toon-shaded stylized render`

**域负面词包（追加到每镜 negative constraints）**：
- A 域：卡通感 / 塑料皮肤 / 影楼打光 / 均匀无方向全局照明
- B 域：photorealistic skin / 3D 渲染感 / 阴影乱爬脸
- C 域：游戏过场感 / 恐怖谷面部 / 廉价渲染

**域法则不可串味**：写实域的光是物理现象（动机光 motivated lighting——每束光说得出来源）；动漫域的光是图形设计（阴影服务脸与情绪，可无源）；3D 域的光是渲染参数（物理正确度是滑杆）。写实 prompt 里混入 `cel shading` = 事故。

## 2. 七步法（Seven-Step Style Bible）

| 步 | 产出 | 好答案判据 |
|---|---|---|
| ① **命门句** keystone sentence | 一句话锁死全剧美学，**必须含对仗或矛盾**（"雪要冷到骨头，火要暖到心口"） | 删掉剧名还能猜出是什么剧；"电影感精美大片"放任何剧都成立=打回 |
| ② **主根脉** main root vein | 从**一种传统艺术/美学体系**选视觉 DNA（禁止选"电影感"——那不是根）+ 为什么是它 + 3 个落地处（构图/材质/转场图形） | 根脉答得出"为什么是它" |
| ③ **辅根脉** sub root veins | 1-2 种，各管一个分区**不许越界**（一种管室内烟火、一种只管兵器出鞘帧） | 每条写明管辖边界 |
| ④ **色彩配方** color recipe | 主三色 + 点缀色 + **禁色清单**（禁色与选色同等重要），hex 锁色 + 占比 | 三色同帧成立；有色彩弧线（颜色随剧情系统变化，预写"第 1 帧什么色→第 N 帧什么色"） |
| ⑤ **差异化签名** signature | 全剧唯一的视觉符号，一句话说清+全剧可执行 | 竞品能直接抄走=不够独 |
| ⑥ **分区应用表** zone table | 场景分区 × 根脉译法 × 色彩 × 光影基准，每个常用场景都有归属 | 抽查任一场景有行可查 |
| ⑦ **验收判据** acceptance criteria | 全部可用 yes/no 回答（随机抽 3 帧遮字幕像同一部剧） | 无形容词判据 |

**粗版（10 分钟开机档）**：第 0 步 + 命门句 + 主根脉一行 + 主三色 hex/禁色 + 签名一句话 + 2-3 条判据。精版再补齐落地处、色彩弧线、分区分光比、签名频度。

## 3. 色彩体系可操作规则

1. **先定和谐结构再填色**：互补（按场景整块切换，日橙夜青）/ 分裂互补（一主两辅）/ 类比色（靠明度质感拉层次）/ 单色统治（颜色升格为标签，内部靠明度分层+小面积异色）。
2. **配方四件套**：主色（统治色，声明占比，如"青灰统治 80%，暖色不超一成"）· 辅色 · 点缀色（小面积，全片唯一"饱和事件"）· **禁色**（最常见事故=AI 偷偷给高饱和糖果色）。
3. **色温两种上限**：冷暖不调匀——环境统一冷，暖只从一个光源漏入；两种色温各有出处（烛光+月光 / 钨丝+夜青）。
4. **饱和度预算**：饱和度=注意力货币，处处高饱和=无焦点；高饱和方案必须同写颗粒/尘土/材质瑕疵兜底。
5. **hex + 比例锁跨集**：按角色/分区定基准 hex，锁比例（80% 低饱和底+单点暖锚），暖锚每帧 ≤1 处。
6. **不可能堆栈禁令**（蒸馏自 Emily2040/seedance-2.0 color-pipeline-aces，MIT）：一镜里塞不下 HDR+16mm+霓虹+漂白+马卡龙商业感这类互斥组合——超出承载就全崩；LUT 名不是魔法词，写 LUT 名必须连带写**可见结果**（"teal-orange grade" 不如 "shadows teal, skin warm, highlights rolled off"）。prompt 只承载色彩意图，调色管线验证属于后期。

## 4. 接入工作流（与 shortdrama-producer 的拼装）

1. **建圣经**：系列短剧在 story-breakdown 之前跑七步法，产出圣经（≤1 页）。
2. **圣经摘要块**（命门句+主根脉+色彩 hex/比+签名规则+禁色）作为**每镜 prompt 风格锚的固定前缀逐字复用**——方向层零漂移的关键。
3. SCENE CONTEXT 引用当前分区对应的根脉译法与色彩配方；negative constraints 追加域负面词包+禁色。
4. 跨集续作：先读圣经再开工；发现镜头与圣经冲突，改镜头不改圣经（除非用户决定升版）。
