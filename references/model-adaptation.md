# 跨模型适配层（Model Adaptation）

> 框架萃取自 [zenstory-ai/drama-skills](https://github.com/zenstory-ai/drama-skills)（MIT）的 target-model-profile（九条能力轴）与 delivery-profile；模型画像为 2026-09 第三方对比数据的快照（**未逐一官方验证，置信度分级标注**；模型迭代极快，投产后以官方文档为准）。跨模型红线另萃取自 super-director FAQ。
> 与 `platform-capabilities.md` 的分工：那边管**平台外壳**（同一模型被不同平台包装后的时长/配额差异）；本文件管**模型方言**（不同模型的正文怎么改写）。

## 0. 定位

shortdrama-producer 的原生规范（OPTICS/`<<<锚>>>`/`—`分段/负面约束/英文正文）是为 Seedance 校准的。换目标模型时**不改工艺、只改方言**——运动配方/表演时序/光影语法/调度规则全部照用，变的只是九条能力轴的取值与正文写法。

## 1. 九条能力轴（换模型先逐条声明，禁止按"据说支持"改写）

| # | 能力轴 | 声明什么 | 正文怎么变 |
|---|---|---|---|
| 1 | 模型版本 | 具体到版本号（Kling 2.5 ≠ 3.0） | 只路由到该版本方言，不按名称相近套用 |
| 2 | 提示词方言 | 通用自然语言 / 原生结构字段 | 命中方言按其字段与素材标记写；语言标签≠方言 |
| 3 | 单次原生时长 | 最短-最长秒数 | 分镜时每镜落在区间内；短动作到位后 hold，长动作按闭合状态拆镜 |
| 4 | 参考条件方式 | 无 / 首帧 / 首尾帧 / 多槽参考（上限） | 见 §5 |
| 5 | 声音同轨 | same_pass / silent | 见 §4 |
| 6 | 画幅与分辨率 | 实际接受的集合 | 只写已接受的那一个，不罗列备选 |
| 7 | 正文长度上限 | 可接受字符数 | 超限先删参考帧已承载的重复描述；连续性锁面与逐字对白不删 |
| 8 | 运镜词汇 | 是否接受具名运镜术语 | 不接受时改写成可见的画面关系变化（主体占画比/边缘进出/遮挡关系），不是换术语 |
| 9 | 正文语言 | zh / en | 正文用该语言；逐字对白保留原口语语言，不翻译 |

**未声明时的回退写法**：按已接受的镜头边界写完整、自足、不依赖任何执行端特性的正文——不做分段、不罗列画幅备选、运镜用可见画面关系描述、声音写职责而非可执行指令。这样的正文在任何模型上都成立，只是没有针对性收敛。

## 3. 方言转换规则（Seedance 规范 → 其他模型）

1. **结构映射**：OPTICS/SCENE CONTEXT/ACTION 分段 → 通用自然语言模型**拍平成段落**（保留顺序：场景光线 → 锚定外观 → 动作链 → 运镜 → 声音）；Veo/Sora 吃结构化长文，可保留分段。
2. **参数值禁写是跨模型红线**：`85mm/f2.8/47°` 一律改写效果（`浅景深，背景虚化主体锐利` / `medium shot, eye-level`）——super-director 实测多模型不认数值。
3. **单镜单向运动**是跨模型红线：复合运镜必糊，拆镜。
4. **运镜词汇降级**（能力轴 8）：不接受具名术语的模型，把 `dolly-in` 写成"人物在画面中逐渐变大/背景向边缘退去"；`whip pan` 写成"画面快速横甩模糊过渡"。
5. **锚定系统**：`<<<名字>>>` 是纯文本约定，任何模型都可保留；但**首尾帧/参考条件弱的模型，锚定外观描述必须更完整**（参考帧承载不了的细节全部写进正文）。
6. **负面词**：多数模型支持简单负面列表；不支持的把关键负面转成正面约束写进正文（如"画面无叠加文字"→"纯净画面，无任何文字元素"）。
7. **spec header**：`Duration: X seconds. Aspect ratio: <ratio>. One continuous shot.` 按目标模型改写——有 UI 参数面板的（Kling/Runway/Pika）时长画幅走面板，正文不再重复；纯 prompt 驱动的（Veo/Sora/Seedance）保留。
8. **语言**：中文系模型（可灵/海螺/即梦）中文正文同样成立且更稳；逐字对白永远保留原口语语言。

## 4. 声音同轨差异

- **same_pass**（Seedance/Veo 3.x/可灵 3.0）：正文写完整声音时间线——封闭事件集合、逐字对白、事件间底声或静默、显式声明无配乐层。规则照 `directorial-craft.md` §3 执行。
- **silent / 音频弱**（Runway/Pika/Wan，及对白同轨弱的 Kling 2.x）：声音段改写**声音职责说明**（谁说话、什么环境声承担信息、转场声落点），服务后期配音与审查，不写成可执行指令；正文显式关掉字幕/文字叠加层（防模型自造字幕）。
- **对白预算逐模型校准**：4.1 字/秒是 Seedance 实测值；对白弱模型对白预算再砍半，或把对白挪到后期。

## 5. 参考条件方式 → 设定图协议映射

| 模型能力 | 我们的协议怎么接 |
|---|---|
| 无参考（纯文生） | 三格设定图协议跳过；锚定外观全量写进每镜正文（角色卡详写） |
| 首帧 | 首帧=设定图正视图渲染结果；正文只写从该起点开始的**变化**（motion-only） |
| 首尾帧 | 尾帧=状态机 end state 的投影；正文写过程，不得发明新结果 |
| 多槽参考 | 直接映射 reference-image-protocol：三格设定图/道具/场景图按槽位挂载，顺序与界面挂图次序一致；槽位超限按重要性取舍并说明放弃了什么 |

**互斥陷阱**：不少执行端首/尾帧输入与多槽参考互斥——此时整组统一走多槽参考，首帧也当参考素材送入，不要拆成"首帧+参考图"两套说明。

## 6. 换模型自检

- [ ] 九条能力轴逐条声明了吗？（没有声明的按回退写法，不猜）
- [ ] 时长/画幅落在该模型甜点区？长动作按闭合状态拆镜？
- [ ] 参数数值清零？单镜单向运动？
- [ ] 声音段写的是"完整时间线"还是"职责说明"（按 same_pass/silent 正确选择）？
- [ ] 逐字对白保留原语言？字幕/文字叠加层显式关闭？
- [ ] 参考槽位与挂载次序一致，无"首帧+参考图"混用？
