# 序列协议（Sequence Protocol）

短剧模式下，镜头不是孤立的：**clip N 的结尾状态决定 clip N+1 的开头**。
只用于短剧模式；单镜头模式不涉及。

## 核心规则

1. **结尾→开头**：每镜 prompt 的结尾帧（end state）必须与下一镜的开头（start state）衔接——空间、动作、角色位置、道具状态连续。
2. **已接受镜头覆盖计划**：用户实际生成并接受的镜头是**唯一事实**。下一镜的 prompt 基于"上一镜实际结果"而非"上一镜计划"。用户反馈"这里不对"→ 修正后该状态进入 canon。
3. **被拒镜头不入 canon**：用户不满意的镜头不能作为下一镜的衔接来源；必须重拍到通过。
4. **批次内顺序生成**：同一批镜头按 1→N 顺序产出；跨批次（用户说"继续"）先回顾上一批最后接受镜头。
5. **连续性状态机**：每完成一镜更新状态（角色位置/道具状态/情绪基调），下一镜读取。

## 连续性状态机

```yaml
当前镜: <N>
上一镜接受: <N-1，end state 一句话>
角色位置: <谁在画面哪里>
道具状态: <关键道具当前状态>
场景光线: <当前光线基调>
情绪基调: <本镜氛围词>
```

每次生成新镜前，先输出/更新状态机（≤6 行），再写 prompt。

## 节拍桶（事件密度防火墙）

> 蒸馏自 Emily2040/seedance-2.0（MIT）`event-density.md`（Emily2040/seedance-2.0）。

一次生成正常只承载**一个可见节拍 + 一个已改变的终点态**。长前史、多地点、多个大动作、密集对白、未来收束，全部属于序列计划，不属于当前 prompt。写每镜前，把剧情事件分进四个桶：

| 桶 | 归属 | 规则 |
|---|---|---|
| `already_happened` | 已发生 | **不许重演**——与状态机"已接受镜头=唯一事实"同源 |
| `this_clip_only` | 本镜 | 只有这个桶允许在本镜正文里**演出来** |
| `reserved_for_later` | 留给后面 | 不许提前演；可在表演/氛围里埋线索，不许给出信息 |
| `do_not_show_yet` | 禁演 | 即使它能解释动机也不出现 |

**范围防火墙**：故事上下文可以 informs 表演、氛围、节奏，但**不得**让本镜提前执行未来事件、泄露未来信息、提前解决后面的问题、跳过物理交接状态（手里没枪就开不了火）。

**拆分触发**：请求含多个已完成动作 / 跨多地点的行程 / 多轮对白 / 复杂肢体接触 / 证明+展示二合一 / 超出该镜时长的故事量——命中即拆镜，拆完按衔接方式回接。

## 单生成内多镜：先选剪辑，再选记法

"多镜"有两种实现，先按用户优先级选路线，再决定要不要写 `Shot 1:` 标号：

| 用户要什么 | 路线 | 代价 |
|---|---|---|
| 一段连续表演 | 写 `single continuous take` + 分阶段 + 终点定格 | 段内剪辑控制力弱 |
| 揭示/反应/对比 | 写两镜 + **驱动切镜的那个动作** | 每镜要留够节拍时间 |
| 快速蒙太奇 | 短促独立画面 + 显式转场 + 总时长合规 | 对白/细节动作/终点定格没空间 |
| 精确到帧的时序 | 拆成独立镜、后期剪辑 | 模型自出时序不可靠 |

单镜 4-6 秒一个动作/反应拍是**排期启发式**，不是下限；`Shot 1:` 标号是教学记法，散文体 "cut to" 同样成立（本项目的序列头继续沿用，供人核对，不假设模型有专门解析器）。

## 镜头衔接写法

### 方式一：延续（推荐，默认）
下一镜 prompt 开头直接承接上一镜结尾：
```
...（上一镜结尾的动作/位置描述）— CONTINUATION: <角色> continues to <动作>，
camera <新机位> now ...
```

### 方式二：时间跳跃（换场/蒙太奇）
显式声明跳变，仍保持视觉一致性（同角色同圣经）：
```
— TIME CUT: <时间差> later, same <scene>，<角色> now <新状态>（引用圣经状态轴）
```

### 方式三：转场特写（衔接道具/视线）
用道具或视线做桥：
```
— INSERT: close-up of <道具>（状态=上镜结尾）; pull back to reveal <新场景/新角色>
```

## 每镜 prompt 的序列字段

短剧模式的每条 prompt 在正文前加 3 行序列头（非正文，供人/工具核对）：
```
# shot N / total | 场 X | 衔接: <延续|时间跳跃|转场特写> from shot N-1
# start state: <一句话>
# end state: <一句话（下一镜要接的）>
```

## 边界

- 用户只生成单镜 → 不输出序列头。
- 用户重拍上一镜 → 以最新接受版为准更新状态机，继续向后。
- 跨镜长时间断档（如隔天继续）→ 先重读连续性圣经 + 状态机再写，不依赖记忆。
