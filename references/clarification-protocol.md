# 澄清协议（Clarification Protocol）

把用户一句模糊想法 → 结构化创意简报。原则：**问得少而准**，一次问完，能猜就猜（标注假设），不把澄清做成问卷。
两种模式：**单镜头模式用五问**，**短剧模式用六问**（多出「结局与节拍」，先做故事拆解）。

## 触发判断

| 情况 | 动作 |
|---|---|
| 用户给出 ≥3 个信息维度（主体/场景/氛围/风格） | 跳过提问，直接生成，写下假设 |
| 用户只有一句话/vibe/概念 | 单镜头用五问、短剧用六问一次问完 |
| 用户给了参考图/参考片 | 沿用其风格，不重复问视觉维度 |
| 用户说短剧/多镜头/分镜/故事 | 直接进短剧模式，按 story-breakdown 拆解 |

## 五问（单镜头模式，一次问完，不分多轮）

1. **主体**：谁/什么？人物（年龄/性别/特征）、怪物、物体、纯环境？
2. **动作**：在做什么？静止氛围（slow cinema）还是事件（追逐/打斗/互动）？
3. **场景与光**：哪里？室内/室外、什么年代/时期、白天/夜、光质（暖/冷/自然/霓虹）？
4. **情绪**：要什么感觉？给 2–3 个形容词（如 tense + atmospheric + nostalgic），或让用户报一个参考片 vibe。
5. **风格锚**（可选）：导演/摄影师/胶片/类型片？用户不熟就由本技能推荐（默认 Lubezki × Deakins + 现代写实）。

## 六问（短剧模式 = 五问 + 结局节拍问）

1-5 同上，第 6 问：
6. **结局与节拍**：故事往哪走（一句话结局）？大概几个节拍（起/承/转/合）？
   追问不细究：用户答不出节拍，就由本技能按三幕结构兜底拆解（见 `story-breakdown.md`）。

## 澄清后的简报格式

### 单镜头简报
```yaml
主体: 谁/什么（含外观关键词，或写"待定，用参考图"）
动作: 一句话情节或"纯氛围"
场景: 地点 + 时间 + 光质
氛围: 2-3 个形容词
风格锚: 导演×摄影师 / 胶片规格 / 类型片（可"推荐"）
规格: 画幅(默认21:9) / 时长(默认15s) / 有声(默认是)
档位: cinema | quick（默认 cinema）
假设: [本技能替用户做的默认假设，用户可改]
```

### 短剧简报（进 story-breakdown 前）
```yaml
模式: short-drama
故事目标: 主角想做什么
最终结局: 一句话结局（用户给 or 本技能提议待确认）
节拍数: 3-8 个（三幕兜底）
场景数: 预计 N 场
镜头预算: 预计 N 镜（单批 ≤6）
风格锚: 同单镜头
假设: [含结局/节拍的默认设计，用户可改]
```

## 假设清单（未问即用的默认值）

- 画幅 21:9、时长 15s、有声、单镜头（源自语料 92%/68%/99.7%/100%）；短剧默认每镜 15s。
- 风格锚默认「现代写实电影感」，若用户提到"酷/炫/动漫"则换对应锚
- 角色命名：按主体语义取小写英文名（如「穿红衣的女孩」→ `red_girl`）；短剧模式命名进连续性圣经并全剧复用
- 无参考图时，角色外观由本技能按简报设计并声明为假设
- 短剧默认三幕结构（开端/冲突/结局），镜头预算按「1 镜≈15s」估算

## 边界

- 用户说"随便/你定" → 本技能自主设计并明确标注所有假设，交付后给 3 个可调项。
- 用户拒绝回答某问 → 跳过该维，用假设填充并在简报标注。
- 澄清绝不问"你想用什么模型参数"这类技术细节——那是本技能的职责。
- 短剧模式的镜头预算必须与用户对齐后才进连续性圣经阶段。
