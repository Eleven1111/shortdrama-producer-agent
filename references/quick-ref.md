## 默认路由

| 用户进来时 | 走哪 |
|---|---|
| 模糊想法/灵感碎片 | 澄清协议（≥3 维度直接做；1–2 维度问 ≤2 个选项题；零信息给 3 方向） |
| 明确需求 | full-direction 完整工作流 |
| 「只要提示词」 | prompt-only，单个 ```text 块 |
| 「只要脚本」 | script-only，无 prompt 包装 |
| 「为什么效果差」 | diagnosis-only：先跑 `scripts/diagnose_prompt.py`，**不重写** |
| 「按我的结构改」 | revision：保结构，只修要害 |
| 短剧/多镜头/分镜 | 短剧模式（story breakdown → 设定图 → 圣经 → shotlist → 逐镜） |
| 点名其他模型 | Step 1.5 → `model-adaptation.md` 方言翻译，工艺层不动 |
| 跨镜角色/道具一致 | Step 4.6 设定图协议 |

## 交付前 12 门

| 门 | 通过条件 |
|---|---|
| 模式 | T2V / I2V / 首尾帧显式；用户素材已建绑定表（一个资产一个角色） |
| 规格头 | Duration / Aspect ratio 来自平台能力表，不硬编码 |
| 主体 | 锚点 `<<<name>>>` 首次出现带完整外观 |
| 动作 | 一个可见节拍有观测得到的终点；起点—变化—终点闭合 |
| 运镜 | 一个主运动，动机答得出来（because the intention is X） |
| 光 | 方向=情绪、来源声明、光比服务剧情跃迁 |
| 音频 | 三轨有意（台词/音效/环境声或显式静默） |
| 负面 | ≥5 条基线 + 反渣词库 §7 该题材禁区 |
| 风格锚 | ≥1；系列片用圣经摘要块前缀 |
| 预算 | 保真预算一镜一主支出（§12）；身份外包给参考图 |
| 终点 | 按终点画像选型（§13），unmatched-motion 律过一遍 |
| 序列 | 序列头齐全；节拍桶分账；`continuity_check.py` 过链 |

## 三个最容易死的地方

1. **短剧一致性死在图上**——文本锚不住，87.32% 真实资产靠参考图；改状态=改设定图版本，不在视频 prompt 里补描述。
2. **续写死在计划态**——必须从已接受镜头的**观测终态**开场；像素上没读到的状态不入 canon。
3. **AI 腔死在词上**——cinematic/epic/dynamic 这类词要么换成可拍摄的决定，要么澄清它背后没决定的事。
