# 出片评分口径（P1 渲染回环）

## 为什么只评这两类

只评 **指令遵循** 与 **技术缺陷**，**不评美学**。

美学判断在 A/B 实验里不可用：它主观、跨评分者不一致、且无法归因到某一条 prompt 改动。
而「prompt 里明写了 handheld，出片是不是 handheld」是二元事实，任何评分者都能给出
同样答案 —— 这才能支撑「加了约束 → 缺陷率下降」这种因果结论。

## 三条硬规则

1. **二元判定**：每项只能是 `pass` / `fail` / `n/a`。禁止 1–5 分制 —— 模糊分数会把
   评分者的美学偏好混进来，正是要排除的东西。
2. **只判 prompt 明写的项**：prompt 没写「不许看镜头」，出片有人看镜头也记 `n/a`，
   不记 `fail`。否则测的是模型默认行为，不是约束效果。
3. **盲测**：评分者拿到的是打乱后的样本，不知道属于 A 组还是 B 组。组别映射由
   `run_ab.py` 单独存盘，聚合时才还原。

## 评分项

### 一、指令遵循（prompt 写了什么，出片做到没有）

| 项 | 判 fail 的条件 |
|---|---|
| `duration` | 成片时长与 `Duration: X seconds` 偏差 >15% |
| `shot_count` | 硬切次数与 shotlist 声明不符 |
| `hard_cut_timecode` | 硬切位置与声明时间码偏差 >0.5s |
| `camera_move` | 声明的运镜（handheld / pan / tilt / push）未出现或明显相反 |
| `lens_locked` | 声明段内锁定焦段，实际出现变焦 |
| `camera_relative_direction` | 声明 `left/right = FROM CAMERA`，实际方位相反 |
| `axis_180` | 声明轴线一致，实际跨轴（人物左右关系翻转） |
| `no_empty_first_frame` | 声明首帧被占据，实际首帧为空镜/黑场 |
| `hold_final_frame` | 声明结尾定帧，实际提前切走或黑场 |
| `character_count` | 画面人数与 prompt 声明不符 |

### 二、技术缺陷（AI 视频的已知失效模式）

| 项 | 判 fail 的条件 |
|---|---|
| `hands_formed` | 任一可见手部出现多指/少指/融合/扭曲 |
| `identity_consistency` | 同一角色跨镜头/跨帧五官或服装发生可见漂移 |
| `prop_consistency` | 关键道具形态/位置发生非叙事性突变 |
| `no_floating` | 人或物违反重力（漂浮、无支撑悬停、脚不着地） |
| `no_smearing` | 运动区域出现拖影/糊化/结构崩解 |
| `no_look_at_lens` | 声明禁止看镜头，演员视线仍直视镜头 |
| `no_slow_motion` | 声明禁止慢动作，出现明显升格 |
| `no_onscreen_text` | 出现未要求的文字、水印、字幕 |
| `not_3d_render` | 声明实拍质感，成片呈现游戏引擎/CG 塑料感 |
| `diegetic_audio` | 声明同期声，出现配乐/旁白 |
| `shutter_cadence` | 运动模糊明显不符合 180° 快门（过于清晰或过度模糊） |

## 谁来评

按可靠性排序，**结果必须标注用了哪种**：

1. **人评**（基准）：最可靠。24 个样本约 1 小时。A/B 首轮建议用这个。
2. **视觉模型评**（可扩展）：抽帧送多模态模型，按上表逐项二元判定。
   必须与人评做一致性校验 —— 在同一批样本上 Cohen's κ < 0.6 则该项不可用模型评分。
3. **自动指标**（仅覆盖少数项）：时长、硬切位置可用 ffmpeg 场景检测客观测量，
   无需评分者。这些项优先走自动。

## 结论怎么算

- 主指标：**每片缺陷数**（fail 项计数）A 组 vs B 组。
- 次指标：分项 fail 率，用于定位是哪条约束在起作用。
- 12 对样本量小，**只报效应量与方向，不做显著性声称**。若 A 组缺陷数不降反升，
  说明 Step 5.5 的约束无效或有害 —— 这是有价值的负面结果，必须如实回写。
